# Graphics

Every graphic from The Weber County Hive and Utah Hive Politics, in one place.

Gallery: https://weber-county-hive.github.io/graphics/

- Each graphic lives in a topic folder: `2026-election/`, `transparency/`, `developments/`, and more as needed.
- `graphics-data.js` lists every graphic (title, topics, date, the story it goes with, where it ran). The gallery page reads it.
- Graphics already used in posts keep their address. Don't rename or move them.
